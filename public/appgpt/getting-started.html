APPGPT QUICK START

Build your first Telegram Mini App

AppGPT turns a plain-language idea into one complete Telegram-ready index.html. Your chat is saved before generation begins, so you can return to the session, keep editing, debug it, and publish it.

✦ Open AppGPTBrowse templatesConnect an AI providerGitHub
1

Connect an AI model

Open Provider. Choose Gemini, Hugging Face, OpenAI, Claude, OpenRouter, or another supported provider. Paste your own API key and test the connection.

2

Start a chat

Describe the app you want. The current chat becomes the app, and future messages keep editing that same app instead of creating a separate project.

3

Create the app

Use Create App to confirm the current chat as your app brief. Inside Telegram, AppGPT uses Telegram's native popup when available.

4

Preview, code, and debug

Switch between Content, Code, Preview, and Debug. Code changes can be saved as versions, while normal chat messages update the current app with AI.

5

Download or publish

Download the generated index.html or publish it through AppGPT's GitHub Pages flow, then use the HTTPS result as a Telegram Mini App URL.

Tip: AppGPT defaults to dark mode and includes a light-mode toggle. LiquidGL is used when available, with a normal glass fallback.
